# SFX Assets

Place three CC0-licensed MP3 files here before running the bot:

- `whoosh.mp3` — ~0.5-1s swipe/whoosh sound (plays at each clip transition)
- `impact.mp3` — ~0.3s hit/impact sound (plays on key words with numbers/$)
- `ding.mp3`   — ~0.5s notification/ding sound (plays on words: free, now, link, click, try)

Source: freesound.org — filter by CC0 license, search "whoosh", "impact hit", "notification ding".
